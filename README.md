## 🚀 Quick Start Guide

### 1. Start Unified Backend API (Port 5000)
```bash
cd "d:\civis_metric  V2\engineering-backend"
npm install
node server.js
```

### 2. Start Frontend Engineering Dashboard (Port 5173)
```bash
cd "d:\civis_metric  V2\my-engineering-dashboard"
npm install
npm run dev
```

## 📐 System Highlights

- **33+ Engineering Calculators**: Core Materials, Structural Members, Geodesy & Land, Finishing, Costing, Advanced MEP.
- **AutoCAD Studio**: Interactive 2D/3D Three.js WebGL drafting canvas with layers and snapping.
- **IS 10262:2019 Mix Design**: Indian Standard concrete mix design module.
- **BBS Rebar Optimizer**: Linear cutting stock scrap reduction for 12m stock bars.
- **Master BOQ & Project Tracker**: Schedule of Rates aggregation and Gantt progress management.
